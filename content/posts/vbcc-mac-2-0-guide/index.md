用 iPhone 控制 Mac 指针，完成点击、拖拽与双指滚动。

需要 **Mac 2.0 或更新版本**、支持触控板的 iPhone 客户端，以及 **Pro**。

<!--more-->

## 下载与安装

- [iPhone 端 · App Store](https://apps.apple.com/app/id6772499540)（iOS 26+）。
- [Mac 2.0 · 网站下载](https://imyiangyang.top/downloads/vbcc-mac-v2.0.dmg)（macOS 13+，支持 Apple Silicon / Intel）。
- [Mac 2.0 · GitHub 下载](https://github.com/imyiangyang/vbcc-mac-release/releases/tag/v2.0)。

打开 DMG，将 VBCC 拖入「应用程序」后启动。

## 使用触控板

连接 Mac 后，在 iPhone 的首页布局设置中切换到「触控板」。

| 手势 | 操作 |
| --- | --- |
| 单指滑动 | 移动指针 |
| 单指轻点 | 左键单击 |
| 单指双击 | 双击 |
| 单指长按后移动 | 拖拽，抬手结束 |
| 双指轻点 | 右键单击 |
| 双指滑动 | 横向、纵向滚动，支持惯性滚动 |

在触控板设置中，可分别调整**指针灵敏度**和**滚动灵敏度**。操作时保持两端连接。

## 常见问题

### iPhone 找不到 Mac

确认两端网络互通，并检查 Mac 防火墙是否阻止 VBCC。建议先连接同一局域网。

### 已连接，但鼠标无法移动

检查 Mac 的辅助功能权限，以及两端当前的连接状态。

### 没有触控板入口，或显示 Mac 不支持

确认 iPhone 客户端支持触控板、已解锁 Pro，且 Mac 端为 2.0 或更新版本。更新后请退出旧应用，再打开新版本。
